# Temporary Email Script

This script allows you to create a temporary email, generate a random password, and receive messages in real-time. It is ideal for situations where you need a disposable email to receive verification codes, confirmations, or other messages.

## Key Features

1. **Create a temporary email**:
   - Generates a temporary email using the `temp-mail.io` API.
   - Displays the generated email and a random password.

2. **Receive messages in real-time**:
   - Lists messages received in the temporary email in a continuous loop.
   - Displays the subject and content of the messages.

3. **Simplicity**:
   - Focused on the core functionality: create email, generate password, and receive messages.
