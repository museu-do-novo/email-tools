# Script de E-mail Temporário

Este script permite criar um e-mail temporário, gerar uma senha aleatória e receber mensagens em tempo real. Ele é ideal para situações onde você precisa de um e-mail temporário para receber códigos de verificação, confirmações ou outras mensagens.

## Funcionalidades Principais

1. **Criar um e-mail temporário**:
   - Gera um e-mail temporário usando a API do `temp-mail.io`.
   - Exibe o e-mail gerado e uma senha aleatória.

2. **Receber mensagens em tempo real**:
   - Lista as mensagens recebidas no e-mail temporário em um loop contínuo.
   - Exibe o assunto e o conteúdo das mensagens.

3. **Simplicidade**:
   - Focado na funcionalidade principal: criar e-mail, gerar senha e receber mensagens.
